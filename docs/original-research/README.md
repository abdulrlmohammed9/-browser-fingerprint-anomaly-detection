# Original master's research

[View the original University of the Cumberlands poster](university-of-the-cumberlands-poster.pdf).

Author: Abdul Rahman Mohammed.

This PDF is preserved as supplied, without modification. It documents the original academic work. The original research source code and dataset are unavailable.

The current repository contains a newly reconstructed, synthetic-data MLOps extension. Its training outputs, metrics, clustering-based novelty approximations and operational screenshots must be interpreted independently of the poster's historical findings.

The reconstruction does not reproduce or verify the original reported false-positive rate or throughput. See the [current technical report](../mlops-technical-report.md) for measured results and limitations.
